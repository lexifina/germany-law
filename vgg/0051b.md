# § 51b Repräsentativität der Verwertungsgesellschaft

(1)
Eine Verwertungsgesellschaft ist repräsentativ, wenn sie für eine ausreichend große Zahl von Rechtsinhabern Rechte, die Gegenstand der kollektiven Lizenz sein sollen, auf vertraglicher Grundlage wahrnimmt.
(2)
Nimmt nur eine Verwertungsgesellschaft, der eine Erlaubnis (§ 77) erteilt wurde, Rechte nach Absatz 1 wahr, so wird widerleglich vermutet, dass sie repräsentativ ist.
