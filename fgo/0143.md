# § 143

(1)
Das Gericht hat im Urteil oder, wenn das Verfahren in anderer Weise beendet worden ist, durch Beschluss über die Kosten zu entscheiden.
(2)
Wird eine Sache vom Bundesfinanzhof an das Finanzgericht zurückverwiesen, so kann diesem die Entscheidung über die Kosten des Verfahrens übertragen werden.
