Vizepräsident Dr. Mommer: Herr Kollege Müller-Hermann, gestatten Sie noch eine Zwischenfrage von Herrn Ertl?
Ertl (FDP) : Herr Kollege Müller-Hermann, finden Sie nicht, daß es, wenn Sie schon so harte Vorwürfe machen, fair wäre, wenn Sie sagten, wo sich die FDP so verhalten hat, oder glauben Sie, daß Sie mit so allgemeinen Verdammungsurteilen dem Parlamentarismus nützen?
Dr. Müller-Hermann (CDU/CSU) : Herr Kollege Scheel will auch eine Frage stellen.
