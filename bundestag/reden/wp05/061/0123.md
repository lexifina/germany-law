Vizepräsident Dr. Dehler: Eine Zusatzfrage.
Schmitt-Vockenhausen (SPD) : Herr Staatssekretär, sind Sie sich bewußt, daß auf Grund der Koppelung dieses Bahnbauprojekts mit dem allgemeinen innerstädtischen Verkehr von Frankfurt am Main natürlich eine sehr langfristige Vertagung befürchtet werden muß? Sehen Sie keine Möglichkeit, eine Lösung aus diesem Paket herbeizuführen?
