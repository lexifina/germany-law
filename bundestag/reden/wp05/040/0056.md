Dr. Dahlgrün, Bundesminister der Finanzen: Nein, das kann ich nicht. Ich glaube auch nicht, daß das Finanzministerium von Rheinland-Pfalz schon die volle Übersicht hat. Sie können sich direkt an das Finanzministerium von Rheinland-Pfalz wenden, oder ich werde, wenn schon eine Möglichkeit für eine Übersicht gegeben ist, mir diese Zahlen vom Finanzministerium von Rheinland-Pfalz geben lassen.
