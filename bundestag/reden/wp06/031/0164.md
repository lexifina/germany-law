Vizepräsident Frau Funcke: Herr Bundesminister, gestatten Sie eine Zwischenfrage?
Susset (CDU/CSU) : Herr Minister, stimmt es, daß eine Einsparung von 1 % nur 150 Millionen DM ausmacht? Sie sprachen aber immer davon, daß Sie meinetwegen den Satz 32,8 auf 32,5 % reduzieren konnten. Gleichzeitig sprachen sie von Einsparungen von 2,1 Milliarden DM.
