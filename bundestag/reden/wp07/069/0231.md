Vizepräsident Dr. Schmitt-Vockenhausen: Eine Zusatzfrage.
Dr. Schwencke (SPD) : Herr Staatssekretär, wodurch erklären Sie es sich, daß diese Zahl so außergewöhnlich klein ist, zumal sie in anderen Ländern wesentlich höher ist? — Darf ich Sie fragen, ob das damit zusammenhängt, daß die Prüfungen, die seitens der Bundesrepublik vorgenommen werden, so umständlich, so zeitraubend und so vielfältig sind.
