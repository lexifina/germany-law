Es geht nicht an, daß Zahlenwerke, die einer parlamentarischen Opposition, die einem Vermittlungsausschuß übereinstimmend von einer Bundesregierung vorgelegt werden, wenn sie plötzlich für die SPD sprechen, von der F.D.P., die nach einer Umfrage von heute morgen noch 5 % Wähleranteil in Deutschland besitzt,

plötzlich so degeneriert werden. Herr Solms, das Spiel läuft hier nicht, damit das klar ist.
