Herr Kollege Grosse-Brömer, stimmen Sie mir zu,

dass das von Kay Nehm sicherlich richtig dargestellte
Szenario auf eine Rechtssituation zurückzuführen ist, die
16 Jahre lang von der CDU/CSU beeinflusst worden ist,
dass erst in jüngster Vergangenheit Verbesserungen im
Rechtssystem der Zuwanderung, insbesondere im

die von Ihnen kritisierten Dinge zu verhindern, und dass
Sie entsprechende Regelungen, die im Zuwanderungsge-
setz zusätzlich aufgenommen werden sollten, abgelehnt

so ist, dass durch das von Ihnen abgelehnte Gesetz genau
die von Ihnen kritisierten Missstände – sie stammen aus
Ihrer Regierungszeit – beseitigt worden wären.
