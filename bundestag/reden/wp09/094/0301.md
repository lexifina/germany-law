Vizepräsident Frau Renger: Eine Zusatzfrage, Herr Abgeordneter Würtz.
(Abg. Peter [Kassel] [SPD] meldet sich zu
einer weiteren Zusatzfrage)
—	Sie hatten zwei Fragen eben.
(Peter [Kassel] [SPD]: Das war lediglich
eine Nachfrage!)
—	Nein, nein, Sie hatten zwei Fragen. Nachfragen gibt es nicht. Tut mir leid.
(Peter [Kassel] [SPD]: Ich habe erst eine
Zusatzfrage gestellt!)
—	Verehrtester, Sie haben ja nochmal eine Frage. Dann können Sie noch einmal nachhaken.
Herr Würtz, Sie haben noch eine Zusatzfrage.
