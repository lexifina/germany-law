Frau Matthäus-Maier (SPD): Herr Dregger, wenn das so ist, wie Sie es zu Recht beschreiben, daß so starke finanzielle Einbußen da sind, wenn von zwei Berufstätigen einer den Beruf für das Kind unterbricht: Können Sie mir dann erklären, warum es eine Ihrer ersten Großtaten war, das Mutterschaftsurlaubsgeld drastisch abzusenken? Denn das hat dagegen geholfen?
