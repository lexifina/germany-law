# Erstes Gesetz zur Änderung des Sprengstoffgesetzes (G-SIG: 10020274)

- Vorgang: 189762 (Wahlperiode 10, Gesetzgebung), https://dip.bundestag.de/vorgang/189762
- Initiative: Bundesregierung
- Beratungsstand: Verkündet
- GESTA: B050
- Zustimmungsbedürftigkeit: Ja
- Sachgebiet: Innere Sicherheit
- Verkündung: BGBl I 1986, 275 (1986-02-21)

<b>Inhalt:</b> Ersetzung der gesetzlichen Sprengstofflisten durch konstitutive Prüfverfahren, Beschränkung von Erlaubniserteilungen zum privaten Umgang mit explosionsgefährlichen Stoffen, Erstreckung der Gültigkeit der sprengstoffrechtlichen Erlaubnisse auf mehrere Verwaltungszweige, Herabstufung von Gesetzesverstößen gegen eine Höchstlagermenge von explosionsgefährlichen Stoffen von Vergehen auf Ordnungswidrigkeiten, Änderung zahlreicher Paragraphen des Sprengstoffgesetzes zur Verwaltungsvereinfachung des Sprengstoffrechts, Neufassungsermächtigung. Bund, Ländern und Gemeinden entstehen durch das Gesetz keine Mehrkosten. <b>Änderungen aufgrund der Ausschußempfehlung:</b> Änderungen. <b>Nebenschlagwörter:</b> Explosionsgefährlicher Stoff * Ordnungswidrigkeit/Herabstufung von Gesetzesverstößen gegen eine Höchstlagermenge von explosionsgefährlichen Stoffen von Vergehen auf Ordnungswidrigkeiten
