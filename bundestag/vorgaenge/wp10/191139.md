# Gesetz zur Entlastung landwirtschaftlicher Unternehmer von Beiträgen zur landwirtschaftlichen Sozialversicherung (Sozialversicherungs-Beitragsentlastungsgesetz - SVBEG) (G-SIG: 10020552)

- Vorgang: 191139 (Wahlperiode 10, Gesetzgebung), https://dip.bundestag.de/vorgang/191139
- Initiative: Bundesregierung
- Beratungsstand: Für erledigt erklärt
- GESTA: F027
- Zustimmungsbedürftigkeit: Ja
- Sachgebiet: Landwirtschaft und Ernährung; Soziale Sicherung

<b>Bezug:</b> Identisch mit F17 <b>Inhalt:</b> Einführung einer Geldleistung des Bundes für bäuerliche Familienbetriebe, die an sozialen Bedürfnissen ausgerichtet ist und für eine Übergangszeit bis zur Neuausrichtung der agrarsozialen Sicherungssysteme eine Entlastung von den überproportional hohen Sozialkosten ermöglicht; die Entlastung wird von den landwirtschaftlichen Alterskassen durchgeführt. Die Aufwendungen des Bundes betragen 450 Mio DM im Jahr. <b>Nebenschlagwörter:</b> Agrarsozialpolitik/Gesetz zur Entlastung landwirtschaftlicher Unternehmer von Beiträgen zur landwirtschaftlichen Sozialversicherung * Sozialversicherungsbeitrag/Gesetz zur Entlastung landwirtschaftlicher Unternehmer von Beiträgen zur landwirtschaftlichen Sozialversicherung * Landwirtschaftliches Einkommen/Gesetz zur Entlastung landwirtschaftlicher Unternehmer von Beiträgen zur landwirtschaftlichen Sozialversicherung
