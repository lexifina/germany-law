# Gesetz über eine Statistik im Güterkraftverkehr 1978 (G-SIG: 00020013)

- Vorgang: 212469 (Wahlperiode 8, Gesetzgebung), https://dip.bundestag.de/vorgang/212469
- Initiative: Bundesregierung
- Beratungsstand: Verkündet
- GESTA: J001
- Zustimmungsbedürftigkeit: Nein

<b>Inhalt:</b> Durchführung einer Bundesstatistik über die Verkehrsleistungen im inländischen gewerblichen Güterkraftverkehr im Jahre 1978. <b>Nebenschlagwörter:</b> Statistik für Bundeszwecke
