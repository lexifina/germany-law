# 2.

(1)
Befinden sich in einem Gebäude mehrere zur Führung des Amtsschildes der Bundesbehörden berechtigte Dienststellen, so können sie ein gemeinsames Schild mit dem Bundesadler verwenden.
(2)
Die Dienststellenbezeichnungen werden in diesem Fall auf besonderen, untereinander aufgehängten Anhängeschildern angeführt.
