# § 62 Ermittlung des substanzbasierten Freibetrags in einem Übergangszeitraum

(1)
Für die Zwecke der Anwendung der §§ 58 und 59 gilt anstelle des Werts von 5 Prozent für jedes Geschäftsjahr, das in einem der folgenden Kalenderjahre beginnt, folgender Wert:
| Geschäftsjahr beginnt im Kalenderjahr | Prozentsatz für § 58 |
| 2023 | 10 |
| 2024 | 9,8 |
| 2025 | 9,6 |
| 2026 | 9,4 |
| 2027 | 9,2 |
| 2028 | 9,0 |
| 2029 | 8,2 |
| 2030 | 7,4 |
| 2031 | 6,6 |
| 2032 | 5,8 |
