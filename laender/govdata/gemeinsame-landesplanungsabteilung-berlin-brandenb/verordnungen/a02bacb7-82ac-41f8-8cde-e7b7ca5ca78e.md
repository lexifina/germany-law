Der interoperable INSPIRE-Datensatz beinhaltet Daten von der GL über den rechtswirksamen Braunkohlenplan Cottbus-Nord im Land Brandenburg (Rechtsverordnung v. 18.07.2006), transformiert in das INSPIRE-Zielschema Geplante Bodennutzung. Er gibt einen Überblick über den Abbaubereich, die Sicherheitszone und die Flächennutzungen der Bergbaufolgelandschaft. Der Datensatz wird über je einen interoperablen Darstellungs- und Downloaddienst bereitgestellt.
  	  	---
  	  	The compliant INSPIRE data set contains data about the lignite mining plan Cottbus-North in the State of Brandenburg (Cottbus-North open-cast mine, statutory ordinance of 18.07.2006) from the GL, transformed into the INSPIRE target schema Planned Land Use. The plan provides an overview of mining areas, safety zones and land uses of the post-mining landscape. The data set is provided via compliant view and download services.
