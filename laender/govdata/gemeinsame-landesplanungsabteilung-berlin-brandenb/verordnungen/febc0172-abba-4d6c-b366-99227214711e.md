Der interoperable INSPIRE-Datensatz beinhaltet Daten von der GL über den rechtswirksamen Braunkohlenplan Welzow-Süd, räumlicher Teilabschnitt II, im Land Brandenburg (Rechtsverordnung v. 02.09.2014), transformiert in das INSPIRE-Zielschema Geplante Bodennutzung. Er gibt einen Überblick über den Ansiedlungsstandort, den Abbaubereich, die Sicherheitszone und die Flächennutzungen der Bergbaufolgelandschaft. Der Datensatz wird über je einen interoperablen Darstellungs- und Downloaddienst bereitgestellt.
  	  	---
  	  	The compliant INSPIRE data set contains data about the lignite mining plan Welzow-South, spatial sector II, in the State of Brandenburg (Welzow-South spatial sector II open-cast mine, statutory ordinance of 02.09.2014), transformed into the INSPIRE target schema Planned Land Use. The Plan provides an overview of settlement sites, mining areas, safety zones and land uses of the post-mining landscape. The data set is provided via compliant view and download services.
