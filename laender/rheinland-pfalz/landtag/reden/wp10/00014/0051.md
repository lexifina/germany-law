Abg. Heizer, SPD:
Herr Kollege Dahmen, weil das offensichtlich für Sie so schwer verständlich ist: Wollen Sie jetzt nach dieser Wonmddung von mir zur Kenntnis nehmen, daß das eine Regelung war, die wegen der geburtenstarkenJahrgänge auf Zeit angelegt war, die Sie gerade als eine Regelung bezeichnet haben, die von der sozialdemokratisch geführten Regierung in Bonn beseitigt worden wäre?
